Engineering Tools In Progress

This section will host browser-based structural engineering tools — calculators, design aids, and visualization apps. Tools are being built progressively. Check back as more are released.

Planned Tools

Beam Calculator Soon

Simply-supported and cantilever beam analysis with shear and moment diagrams for point and distributed loads.

Load Combination Generator Soon

Generate ASCE 7 / IS 875 load combinations from user-defined load cases, with results in a tabular format.

Column Interaction Diagram Planned

Interactive biaxial column interaction diagram per ACI 318, with adjustable bar layouts and live visualization.

Bracing Stiffness Visualizer Planned

Side-by-side stiffness comparison of X, V, inverted-V, K, and EBF bracing configurations with animated deflected shapes.

Diaphragm Behavior Tool Planned

Visualize rigid vs. semi-rigid diaphragm load distribution across resisting elements for irregular floor plates.

Section Property Calculator Planned

Compute area, centroid, moment of inertia, and section modulus for built-up and custom shapes.
